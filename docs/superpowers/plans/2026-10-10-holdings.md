# 持仓列表与成本价风险标注 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户在 `config/holdings.yaml` 维护持仓（代码+每股成本），工具运行时把持仓股并入扫描清单与其他股票去重后统一评估，浮亏超阈值时在风险列提示。

**Architecture:** 自底向上：配置层（holdings.yaml + HoldingCfg + risk_hints.holding_loss）→ 编排层（`_scan_stocks` 扩展为自选∪成分股∪持仓并返回成本映射、`_stock_result` 计算 holding）→ 渲染层（`(持仓)` 标记 + 风险列浮亏提示 + 详情行）→ 快照/skill（schema 2→3）→ 文档。每个任务连同测试一起改，每任务结束时全量测试绿。

**Tech Stack:** Python 3 / pandas / pytest / tabulate。测试一律 `.venv/bin/pytest`。

**Spec:** `docs/superpowers/specs/2026-10-10-holdings-design.md`（本计划按它执行；口径决策以它为准）

## Global Constraints

- **只标注不参与打分**：`scorer.py`、`reporter._signals`、`ranked_rows`、排序/信号/覆盖/总分路径**零改动**。
- **浮亏口径**：`pnl_pct = (price - cost) / cost × 100`；现价取 spot 的 `price`；行情缺失 → `holding = {"cost": …, "pnl_pct": None}`（有成本但无法估算浮亏）。
- **阈值**：`pnl_pct <= holding_loss` 才提示；模块常量 `HOLDING_LOSS_DEFAULT = -10.0`，`risk_hints.holding_loss` 可覆盖；文案 `持仓浮亏 {abs(pnl):.0f}%`。
- **去重**：自选名优先 → 成分股名其次 → 持仓补充（持仓条目初始 `name=code`）；纯持仓股名称从 spot 的 `name` 回填（行情缺失显示代码）。
- **持仓不参与 `candidate_top_n` 裁剪、不占名额**（与自选同待遇）；但持仓代码必须进入 `all_stocks` 的行情批量请求（否则浮亏无法计算）。
- **成本价原样使用**，工具绝不自动调整。
- **`SNAPSHOT_SCHEMA` 2 → 3**；`snapshots/` 下已提交文件与 `cache/` 不改；`docs/superpowers/` 历史文档不改。

```python
def _parse_holdings(path: Path, data: Any) -> list[HoldingCfg]:
    holdings: list[HoldingCfg] = []
    for i, item in enumerate(_list_section(path, "holdings", data)):
        if not isinstance(item, dict):
            raise ConfigError(f"{path}: 'holdings[{i}]' 必须是映射")
        code = _required_str(path, item, "code", f"holdings[{i}].code")
        cost = item.get("cost")
        if isinstance(cost, bool) or not isinstance(cost, (int, float)) or cost <= 0:
            raise ConfigError(
                f"{path}: 'holdings[{i}].cost' 必须是正数（每股成本，元），实际为 {cost!r}"
            )
        holdings.append(HoldingCfg(code=code, cost=float(cost)))
    return holdings
```

```python
def _scan_stocks(watchlist, constituent_entries, holdings=()):
    """扫描清单 = 自选 ∪ 成分股 ∪ 持仓（按代码去重；自选优先保留名称）。

    返回 ``(stocks, holding_costs)``：持仓股随清单一并评估，``holding_costs``
    是代码 → 每股成本（元）的映射（持仓代码必在其中，无论是否新并入清单）。
    """
    stocks = list(watchlist)
    known = {stock.code for stock in stocks}
    for entry in constituent_entries:
        code = str(entry.get("code") or "")
        if code and code not in known:
            stocks.append(
                config.StockCfg(code=code, name=str(entry.get("name") or code))
            )
            known.add(code)
    holding_costs: dict[str, float] = {}
    for holding in holdings:
        if holding.code and holding.code not in known:
            stocks.append(config.StockCfg(code=holding.code, name=holding.code))
            known.add(holding.code)
        holding_costs[holding.code] = holding.cost
    return stocks, holding_costs
```

```python
def _risk_hint_phrases(item: dict, risk_hints: dict | None) -> list[str]:
    """流动性/持仓提示（只标注，不影响分数）：达到阈值才出现。

    波动率自成为打分指标后不再在此提示——0.0 档会经零分档展示进风险列，
    避免同一列出现两个口径的波动率数字。持仓浮亏紧随流动性提示之后。
    """
    hints = risk_hints or {}
    turnover_low = float(hints.get("turnover_low", TURNOVER_LOW_DEFAULT))
    holding_loss = float(hints.get("holding_loss", HOLDING_LOSS_DEFAULT))
    phrases = []
    turnover = item.get("turnover_wan")
    if turnover is not None and float(turnover) < turnover_low:
        phrases.append(f"日均成交 {_amount_text(float(turnover))}")
    holding = item.get("holding")
    pnl = holding.get("pnl_pct") if holding else None
    if pnl is not None and pnl <= holding_loss:
        phrases.append(f"持仓浮亏 {abs(pnl):.0f}%")
    return phrases
```
