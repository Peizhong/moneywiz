# 分红筛选器（Dividend Screener）

一款基于 Python 的命令行投资辅助工具：维护自选股票与基金列表，运行后自动拉取
行情、分红、估值数据（数据源 [akshare](https://akshare.akfamily.xyz/)，免费、无需注册），
按红利策略多因子加权打分，在终端输出按总分降序排列的股票表、基金表和摘要。

## 环境安装

需要 Python 3.12+：

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt        # 运行依赖
.venv/bin/pip install -r requirements-dev.txt    # 开发依赖（pytest）
```

## 配置文件

四个 YAML 都在 `config/` 下，缺失或格式/字段不合法会在启动时报错并指出具体文件：

### `config/stocks.yaml` — 自选股票

```yaml
stocks:
  - code: "000001"    # 6 位代码，字符串
    name: "平安银行"
```

### `config/dividend_index.yaml` — 红利指数成分股（自动维护）

```yaml
index_code: "000015"                 # 上证红利指数（510880 跟踪）
updated_at: "2026-10-06T12:00:00"    # 最近一次刷新时间
constituents:
  - code: "600015"
    name: "华夏银行"
  - code: "601088"
    name: "中国神华"
    added: "2026-10-06"              # 可选：本次刷新新加入的成分股会带该字段
```

`updated_at` 超过 `index_refresh_days`（rules.yaml，默认 14 天）时，运行会自动向
中证指数官网刷新：新增成分股写入 `added` 字段并在当次报告的股票名后标注 `(新增)`，
被调出的个股从文件中移除（日志会列出新增/调出）。刷新失败时沿用现有名单并告警，
不中断运行。运行时扫描 **自选 ∪ 成分股**（按代码去重，自选优先）。

### `config/funds.yaml` — 自选基金

```yaml
funds:
  - code: "510880"
    name: "红利ETF"
    type: etf         # etf | lof | normal
    index: "上证红利"  # 可选；须在 akshare stock_index_pe_lg 支持的指数名单内
```

`type` 决定数据来源与折溢价口径：`etf` 用行情表的 IOPV，`lof` 用最新单位净值，
`normal`（场外开放式）无市价，折溢价指标不可评分。`index` 留空时按基金概况的
跟踪标的自动推断是否可算指数估值分位。

### `config/rules.yaml` — 权重与阈值

- `stocks.indicators` / `funds.indicators`：每个指标的 `weight`（各自总和必须为 100）
  与阈值档位；指标值按阈值分为 1.0 / 0.5 / 0.0 三档；
- `data`：`kline_days`（K 线/净值窗口天数，默认 120）、`pe_cache_days`
  （行业 PE/PB 缓存有效期，默认 7 天）、`financial_cache_days`（年报可持续性数据
  缓存天数，默认 30 天，财报季度更新）、`index_refresh_days`（成分股自动刷新
  阈值，默认 14 天）、`market_cache_hours`（行情/分红/净值类取数的通用缓存时长，
  默认 24 小时——期内重复运行不再请求上游）；
- `output`：`buy_top_n`（前 N 名标「买入」）、`avoid_bottom_n`（末尾 N 名标「末位」）。

## 运行

```bash
.venv/bin/python main.py     # 或先激活 venv，再执行 python main.py
```

在项目根目录执行；配置与缓存分别读写 `config/` 与 `cache/`（行业 PE/PB 缓存
`cache/pe_cache.json`，过期为 `pe_cache_days` 天；年报可持续性缓存
`cache/financial_cache.json`，过期为 `financial_cache_days` 天；行情/分红/净值等
取数统一缓存在 `cache/market_cache.db`（SQLite），过期为 `market_cache_hours`
小时——24 小时内重复运行不再请求上游接口）。东财行情（push2 系列）调用失败会
熔断 30 分钟并持久化在同一个缓存库：期间直接使用腾讯回退源或按数据不足处理，
避免每次运行都为被拒的接口重复等待；运行间隔内的第二次运行通常只需 1-2 秒。
配置错误时打印错误并返回退出码 1，
正常结束返回 0。

### Docker

```bash
docker build -t moneywiz .
docker run --rm moneywiz           # 直接运行筛选，无需任何挂载
docker run --rm moneywiz pytest    # 容器内跑测试
```

构建时把本机的 `config/`（自选、规则、成分股）与 `cache/`（行情/财报缓存）
一并打进镜像，**不需要挂载**——改了自选/规则后重新 `docker build` 即可。
镜像内的缓存是构建时的快照：24 小时 TTL 到期后容器会自动重新拉取；容器内
新增的缓存随 `--rm` 消失，需要跨运行保留时自行挂 `-v` 或改用 `docker commit`。
容器以非 root（uid 1000）运行；时区默认 `Asia/Shanghai`，可用 `-e TZ=...` 覆盖。

## 输出说明

```
【板块温度计】中证红利股息率 4.14%，10Y国债 1.82%，利差 +2.32pct，上证红利PE分位 14%
【股票】
  排名      代码  名称      总分  覆盖    信号    亮点        风险         技术
----  ------  ----  ----  ----  ----  --------  ---------  --------------
   1  000001  平安银行  92.5  7/7   买入    股息率 5.9%、连续分红 24年  -          MACD 金叉 RSI 56
   2  300750  宁德时代  58.3  3/7   观察    股息率 3.1%、120日中位 44%  连续分红 2年  RSI 42
   3  600036  招商银行  25.0  7/7   末位    120日低位 18%          连续分红 2年、PB估值 +35%  RSI 42
【基金】
  排名      代码  名称       总分  覆盖    信号    亮点        风险    技术
----  ------  -----  ----  ----  ----  --------  ----  ----
   1  510880  红利ETF  75.0  5/5   买入    折溢价 -1.20%、基金规模 223亿、120日低位 12%  -     -
扫描 4 只标的（股票 3 / 基金 1），数据不足 0，指标不全 1，耗时 12.3s
```

（示例使用 `output: {buy_top_n: 1, avoid_bottom_n: 1}`。）

- **板块温度计**（报告首行）：中证红利指数股息率（中证指数官网）、10 年期国债收益率
  （近 90 天窗口）、两者利差（pct），以及上证红利 PE 历史分位（乐咕乐股，全历史区间
  近似分位）。用于判断红利资产的相对配置价值；任一字段取不到时跳过该字段，全部取不到
  时不显示该行。
- **总分**：各指标按阈值分档（1.0 / 0.5 / 0.0）后按权重加权，满分 100；只对能拿到
  数据的指标重新归一化。这意味着个别指标缺失不会直接拉低分数，但反过来，高分也可能
  只由少数几个指标支撑——请同时看「覆盖」列，覆盖低的分数代表性有限。全部指标都
  拿不到数据时显示 `N/A`，信号为「数据不足」。
- **覆盖**：该标的已评分指标数 / 应有指标总数（如 `7/7`、`3/7`；一个指标都没评到
  时如 `0/7`，基金为 `0/5`）。覆盖不全时分数只反映已评分的那部分指标。
- **信号**：按表内排名给出 —— 前 `buy_top_n` 名「买入」、末尾 `avoid_bottom_n` 名
  「末位」、其余「观察」；无分标的固定为「数据不足」，不占用买入/末位名额。
  同分标的共享名次（竞赛排名，显示为 `1(并列6)`），边界上的同分不会被代码排序切开；
  「买入/末位」都是**表内相对**标签，不代表绝对买卖建议。
- **名称标记 `(新增)`**：该股在近 `index_refresh_days` 天内新加入红利指数成分股
  （对应 `dividend_index.yaml` 里的 `added` 字段），仅在刷新后的一段时间内标注。
- **分红可持续性（并入风险列 + 总分扣分）**：按最新年报检查 —— 净利润增长率 < 0
  提示「盈利下滑 X%」；每股经营性现金流 ≤ 0 提示「经营现金流为负」；近 12 个月每股
  分红 ÷ 每股经营性现金流 > 100% 提示「分红超现金流 X%」。红标同时**扣总分**：
  盈利下滑 -10%、现金流为负 -15%、分红超现金流 -10%（合计封顶 -30%，在
  `rules.yaml` 的 `stocks.sustainability` 可调），避免"掏空式分红"拿高分。
  年报数据源为新浪财经（按 `financial_cache_days` 缓存），获取失败时无此项。
- **波动率 / 流动性提示（并入风险列，只标注）**：年化波动率 ≥ `volatility_high`
  （默认 35%）提示「波动率 X%」；近 60 日均成交额 < `turnover_low`（默认 5000 万）
  提示「日均成交 X万/亿」。阈值在 `rules.yaml` 的 `stocks.risk_hints` 可调。
- **分红趋势（参与打分，权重 10）**：近 3 个年度 vs 前 3 个年度每股分红变化率，
  ≥0 / ≥-30% / 更差 对应 1.0 / 0.5 / 0；前 3 年无分红但近 3 年有 → 视为增长。
- **亮点 / 风险**：满分档（1.0）与零分档（0.0）的指标「名称 + 数值」（单位随指标，
  如 `股息率 5.9%`、`PE估值 +35%`），各最多两项；无则显示 `-`。
- **位置（并入亮点/风险文字）**：「120日低位/中位/高位 X%」= 最新收盘价在近
  `kline_days` 根（默认 120 根，约半年）K 线 [最低, 最高] 区间中的分位。≤30% 视为
  低位（并入亮点），≥70% 视为高位（并入风险），30%–70% 以中性文字并入亮点；无 K 线
  数据时不显示。基金用净值序列按同一规则计算。
- **技术**：股票的 MACD 信号（金叉/死叉）与 RSI 数值，仅作参考，不参与打分。
- **摘要行**：扫描标的数（股票/基金）、数据不足数（完全无法评分的标的数）、指标不全数
  （已评分但有部分指标缺失的标的数）、耗时。

## 已知限制

- **数据源回退（东财 → 腾讯）**：`push2*.eastmoney.com` 会按出口 IP 拒绝海外请求
  （实测海外直连时 TLS 握手成功即被断开），个股行情与 K 线在东财失败时自动回退腾讯
  （`qt.gtimg.cn` 批量行情、`web.ifzq.gtimg.cn` 前复权日线），基金历史回退到
  `fund_open_fund_info_em` 的单位净值走势。回退会记录「回退…」warning；基金净值趋势
  回退后基于净值而非市价（语义不变）。东财独有、无等价公开源的两项在海外网络下仍为
  「数据不足」：行业 PE/PB 对比、ETF IOPV 折溢价。
- **东财行情路径未在本环境真实联调**：本开发环境出口 IP 被 `push2*.eastmoney.com`
  拒绝，`stock_zh_a_spot_em`、`stock_zh_a_hist`、`fund_etf_spot_em`/`fund_lof_spot_em`、
  行业板块接口的字段映射依据 akshare 1.19.1 源码核对；腾讯回退路径已实测可用。
  `stock_history_dividend_detail`、`fund_open_fund_info_em`、`fund_overview_em`、
  `stock_index_pe_lg` 已验证可用。
- **akshare 上游接口变更**：接口不可用或字段改名时会记录 warning，日志与错误信息
  指向具体的 akshare 函数名（如 `stock_zh_a_spot_em`），便于定位是哪个上游接口失效；
  该数据源对应的指标降级为「数据不足」，不会中断整体运行。测试全部使用 mock，不联网。
- **数据时效**：行情/净值来自公开接口，可能有延迟；行业 PE/PB 最多缓存
  `pe_cache_days` 天，指数 PE 分位取历史区间近似分位，均非投资建议。
